# Логотип Software and Computer Museum у SVG

Векторна версія логотипа, відтворена з `source/SCM_logo-1.png` (425 × 579, прозоре тло).
На сторінці використано лише `scm-mark-on-blue.svg` (favicon); решта варіантів — для шапки, друку й соцмереж.

## Файли

| Файл | Колір | Де використовувати |
| --- | --- | --- |
| `scm-logo.svg` | білий + жовтий квадрат, прозоре тло | на синьому тлі (шапка, перший екран, підвал) |
| `scm-logo-blue.svg` | синій #42578C + жовтий, прозоре тло | на білому чи paper-тлі |
| `scm-logo-on-blue.svg` | білий + жовтий на синьому прямокутнику | соцмережі, документи, де тло невідоме |
| `scm-logo-horizontal*.svg` | ті самі три варіанти | горизонтальна версія для шапки й вузьких місць |
| `scm-mark*.svg` | ті самі три варіанти | лише знак без напису: favicon, іконка, дуже малі розміри |

Кольори з ТЗ: синій `#42578C`, жовтий `#FAE530`, білий.

## Як зроблено й наскільки точно

- **Знак** (сітка квадратів, монітор, клавіатура) складається лише з прямих ліній, тому зібраний із прямокутників по пікселях оригіналу. Збіг з PNG — 100 %, кути прямі за будь-якого масштабу.
- **Напис** «SOFTWARE and COMPUTER MUSEUM» обведено кривими (potrace) з PNG, збільшеного в 4 рази. Збіг з оригіналом — понад 97 % пікселів, розбіжності лише на краях літер.
- Тонкий рядок дрібного тексту під словом COMPUTER в оригіналі має висоту 5 px і не читається, тому в SVG він — декоративна смужка.
- **Горизонтальна версія — наша збірка**, не офіційний файл: знак ліворуч, напис праворуч, знак масштабовано до висоти напису. Горизонтальна назва з обкладинки (шапка.png) — окремий шрифтовий напис, і без файлу у високій роздільності його не відтворити.

## Обмеження

Джерело має лише 425 px завширшки, тож при великому збільшенні (банер, друк понад ~15 см) краї літер злегка нерівні.
Для друку краще попросити в музею або дизайнера оригінальний векторний файл (AI, EPS, PDF чи SVG).
