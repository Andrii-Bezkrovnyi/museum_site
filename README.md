# Software and Computer Museum — сторінка сайту

Сторінка про курси, оглядову екскурсію й експонати [Software and Computer Museum](https://sncmuseum.org) — музею комп'ютерів і програм у Харкові. Вона стає початком редизайну сайту sncmuseum.org і задає для нього стиль.

**Головна дія відвідувача:** зателефонувати на **067 539 4095** і записатися на безкоштовний курс або екскурсію.

## Що є на сторінці

1. **Шапка** — знак музею, меню, перемикач UA / EN, телефон.
2. **Перший екран** — заголовок «Доторкніться до історії комп'ютерів», що друкується по літерах, і дві картки: курси й екскурсія.
3. **Курси** — три безкоштовні курси:
   - просунутий курс з AI для дорослих 30+;
   - курс з Roblox для дітей 10–12 років;
   - базова комп'ютерна грамотність + AI для людей 40+.
4. **Екскурсія** — оглядова, 30 хвилин, для всіх, група до 10 осіб.
5. **Експонати** — шість карток: Magnavox Odyssey, Nintendo Famicom, Apple IIGS, Commodore Amiga 600, Apple MessagePad, Apple QuickTake 100.
6. **Коротка історія музею** — хронологія 2017–2026.
7. **Новини та анонси.**
8. **Контакти** — адреса, метро, години роботи, телефон, карта OpenStreetMap.
9. **Підвал** — меню, пошта, соцмережі, юридичні документи.

**Можливості:**
- **дві мови:** українська й англійська; вибір мови запам'ятовується, а `?lang=en` в адресі відкриває англійську версію;
- **адаптивність:** комп'ютер, планшет і телефон; на телефоні меню згортається, а внизу закріплена кнопка «Зателефонувати»;
- **запис дзвінком:** усі номери відкривають дзвінок `tel:+380675394095`, форм на сторінці немає.

## Як переглянути

Сторінка статична: HTML, CSS і JavaScript без збирача й залежностей. Шрифти й карта завантажуються з інтернету.

```bash
python -m http.server 8765
```

Після цього відкрийте http://localhost:8765/.

## Структура

```
index.html            сторінка: українська розмітка з ключами data-i18n
css/
  tokens.css          токени дизайн-системи «Сайт музею» v2: кольори, шрифти, відступи, кути, тіні
  components.css      кнопки й закріплена кнопка дзвінка
  page.css            розкладка блоків для комп'ютера, планшета й телефона
js/
  texts.js            усі тексти українською (uk) і англійською (en)
  i18n.js             перемикач мови
  typewriter.js       друк заголовка по літерах
  menu.js             згорнуте меню
assets/logo/          логотип музею у SVG (див. assets/logo/README.md)
```

## Як змінити текст

Кожен текст на сторінці має ключ в атрибуті `data-i18n` (або `data-i18n-attr` для підписів).
- **Українська версія** — у розмітці `index.html` і в `js/texts.js` (розділ `uk`).
- **Англійська версія** — лише в `js/texts.js` (розділ `en`), за тим самим ключем.

Українську правте в обох місцях: без JavaScript сторінка показує текст із розмітки, а при перемиканні мови — зі словника.

## Дизайн

Розкладка й тексти взяті з дизайну сторінки. Кольори, шрифти, відступи, кути й тіні — з дизайн-системи «Сайт музею» v2; токени мають ті самі назви, що в її `tokens.json`.

| | |
| --- | --- |
| Шрифти | Rubik 600 — заголовки; Literata — текст (не менше 18 px); IBM Plex Mono — позначки |
| Кольори | museum-blue `#42578C`, museum-blue-deep `#2A3859`, ink `#1F2637`, тло paper `#F6F5F0`, blue-soft `#E6EAF3` |
| Акцент | жовтий `#FAE530` — лише кнопки «Записатися на курс» |
| Форма | кути 4 / 12 px, кнопки-«пігулки», м'які тіні |

## Доступність

Мета — WCAG 2.1 AA:
- контраст тексту не менше 5,78:1;
- усі елементи доступні з клавіатури, фокус видно, є посилання «Перейти до змісту»;
- клікабельні елементи на телефоні щонайменше 48 × 48 px;
- при `prefers-reduced-motion` анімації вимикаються, а заголовок одразу показується повністю.
